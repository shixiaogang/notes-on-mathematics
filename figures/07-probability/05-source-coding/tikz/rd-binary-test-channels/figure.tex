% Original analytic teaching diagram, 2026-11-12.
% Optimal test channel for X~Bern(0.3), Hamming distortion, D=0.1.
% (a) reverse form: hat X ~ Bern(0.25), X = hat X xor Z, Z~Bern(0.1) independent of hat X;
%     P(X=1)=0.25*0.9+0.75*0.1=0.3.
% (b) forward form by Bayes: q(1|0)=0.25*0.1/0.7=1/28=0.0357, q(0|1)=0.75*0.1/0.3=0.25.
