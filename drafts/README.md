# 数学草案与待迁移材料

[数学十卷大纲](math-ten-volumes/README.md)是当前正在调整的目标结构，包含十卷、29个部分、133章。总索引与29份部分大纲从机器学习笔记的数学大纲工作区同步，保留原文和相对目录，尚未据此重组正文。已迁入的五卷正文及其实际进度见[正文大纲索引](../plans/README.md)。

[勒贝格测度与积分待迁移稿](volume-02-lebesgue-pending-migration/README.md)保留早先从基础数学中移出的原始正文与提要，尚未接入出版入口。后续迁移时须与当前测度、积分正文核对内容归属及重复，并更新输入路径。

十卷大纲的卷、部分和章目登记在[结构清单](../scripts/outline/math-ten-part-files-manifest.json)中。维护后可在仓库根目录运行 `python3 scripts/check_outline.py`，检查标题、编号、总索引、段落概述及本目录和 `plans/` 中的文件链接。
