# 卷5《优化》：非光滑优化大纲

所属：卷五《优化》第三部分“非光滑优化”（第11章）。卷入口：[volume.tex](../../../tex/05-optimization/volume.tex)；部分入口：[part.tex](../../../tex/05-optimization/03-nonsmooth-optimization/part.tex)。

## 部分主线与导读

部分主线：本部分研究普通梯度不存在时怎样判别最优、怎样推动迭代。第11章依次建立次微分和次梯度方法、邻近映射和复合优化、光滑化，以及上界代理与束方法。

部分导读（`\BookPartGuide`）的自然段：

1. 说明绝对值、最大值和稀疏惩罚的不可微点常常正是最优解所在，因而不能忽略，提出本部分的问题。

2. 概述第11章的路线：次微分判别最优，邻近映射处理可分的非光滑项，光滑化改变目标并需同时控制替代误差与求解误差，最后用代理模型。

## 第11章 非光滑优化

正文入口：[非光滑优化](../../../tex/05-optimization/03-nonsmooth-optimization/01-nonsmooth-optimization.tex)

章职责与主线：处理不可微目标。先以次微分建立最优性判据，再按所用信息依次研究次梯度法、邻近方法（含ISTA、FISTA）、光滑化（Huber、Moreau、Nesterov平滑）与代理模型（MM、束方法），并分别核对可计算性、原目标误差与适用条件。

章首导言：

1. 用两个特征拟合三个观测的$\ell_1$惩罚最小二乘实例引入，给出解$(2,0)$第二系数为零的事实。
2. 指出解恰好落在不可微点，已有基于梯度的方法无法直接使用。
3. 说明先建立判据，再用次梯度直接替换梯度，代价是慢。
4. 说明后面三节分别用保留结构、磨平尖点、逐轮建模三种办法把结构用回来。
5. 给出贯穿全章的三段折线与菱形目标。
