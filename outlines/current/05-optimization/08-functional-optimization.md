## 第29章 泛函优化

正文入口：[泛函优化](../../../tex/05-optimization/08-functional-optimization/01-functional-optimization.tex)

章职责与主线：以固定端点曲线和积分能量为例，把未知量为函数的优化问题放进全卷框架：先用弱收敛与直接法证明极小点存在，再建立泛函的微分、梯度与最优性判别，导出Euler–Lagrange方程和边界条件，最后用试探空间化成有限维计算，并逐处说明向量类比在哪里失效。具体方程理论归卷六，分布变分归卷七。

章首导言：

1. 用最短曲线和被弹簧拉向横轴的细线提出未知量是整条曲线的问题，引出泛函。
2. 说明把区间切分后函数成为长向量，类比贯穿全章，但有几处失效。
3. 按有限维“先存在、再判别、后计算”的顺序列出无限维要重新检查的现象：闭球不紧、可微与梯度依赖空间、局部极小依赖范数、二阶正定不够。
4. 介绍各节分工：问题写法、存在性与反例、微分与梯度、最优性判别、积分目标、有限维近似。

### 29.2 极小值的存在

1. 提出不解方程而断定有解的问题，说明最优性条件都以极小点存在为前提。

###### paragraph：有限维的论证在哪里断开

1. 回顾三关论证，指出第一关在有限维靠紧性。
2. 用正弦标准正交列两两距离为根号2，说明无限维有界闭集不紧。

###### paragraph：换一种看极限的方式

1. 观察高频正弦的读数趋零而长度不变。
2. 配图：振荡函数与读取、范数对比。
3. 定义对偶空间和弱收敛，并写出Hilbert形式。
4. 给出反射空间有界序列的弱子列和范数弱下半连续两条结论，指向卷四线性泛函，并以正弦列说明不等号可严格。
5. 说明后两关也要改成弱极限形式。
6. 定义弱序列闭与弱序列下半连续。
7. 说明这两种弱条件比范数条件更强，反向不成立。

###### paragraph：存在定理

1. 用图说明直接法四步，有限维中前两步合一。
2. 配图：极小化序列经有界、弱子列、可行、最优四步及有限维对应。
3. 陈述直接法定理：反射、弱序列闭、弱序列下半连续和一个有界下水平集给出最优解。
4. 证明：取极小化序列，选弱子列，极限可行，由弱下半连续夹出最优值。
5. 命名直接法，说明强制性是有界下水平集的常见来源，并概括各条件的作用。

###### paragraph：怎样检查弱条件

1. 说明直接验证弱条件困难，凸性可把它化成范数条件。
2. 陈述并证明Hilbert空间闭凸集弱序列闭，方法是最近点变分不等式对弱极限取极限。
3. 解释分离超平面的几何含义，并说明一般情形是Mazur定理。
4. 陈述并证明凸且下半连续蕴含弱序列下半连续，方法是下水平集弱序列闭。
5. 检查能量例子的可行集、凸性、连续性和有界下水平集，得到极小点存在。

###### paragraph：积分目标的存在定理

1. 说明把密度分成导数部分和函数值部分。
2. 陈述可分离密度的存在定理，要求G凸连续且二次增长，V连续下有界。
3. 证明：由增长和Poincaré得有界下水平集，边界集弱序列闭，函数部分靠一致收敛，导数部分靠凸性与Fatou。
4. 总结函数值和导数在证明中的分工，并说明能量满足定理。

###### paragraph：第一关失败：序列没有界，或者没有弱极限

1. 用x平方加权的目标和折线列算出目标2/(3k)，去掉强制性。
2. 证明极小点不存在，并指出导数长度发散。

4. 给出W11上的目标，由总上升量得J不小于1，并用x的k次幂趋近。
5. 证明不达到，序列有界但无弱子列，说明反射性缺失，呼应增长条件。

###### paragraph：第二关失败：弱极限不可行

1. 在单位球面上取质量集中问题和尖峰序列，算出目标1/(2k)。
2. 配图：球面上的集中序列及长度、读取、目标值。
3. 证明不存在极小点、序列弱收敛到不可行的零，说明换成闭球后有解。

###### paragraph：第三关失败：弱极限比序列差

1. 写出双势阱目标，用k齿锯齿算出目标1/(12k平方)。
2. 配图：锯齿序列和非凸G的弦。
