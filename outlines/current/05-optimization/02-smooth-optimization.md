部分主线：本部分研究怎样把梯度和Hessian提供的局部信息变成一步好的移动。第5章准备光滑性上界、步长规则和成本口径；第6至8章按曲率信息分别讲一阶方法、二阶方法和拟牛顿法；第9章先划定局部模型可信的范围再求步；第10章处理非凸目标中的鞍点。

3. 说明第9章改变更新的组织方式，第10章处理鞍点和负曲率。

4. 提示同一算法在强凸、凸和非凸目标上的保证形式与评价量不同。

### 5.1 光滑性

3. 定义梯度Lipschitz条件、L光滑与光滑常数。
4. 说明定义推广了5.1章只对二阶可微使用的L，并用导数曲线的双锥解释条件。

###### paragraph：三个相近的条件

1. 用(2/3)|x|^(3/2)说明处处可微且导数连续却在原点没有光滑常数。
2. 用x^4说明无穷次可微也没有全局常数，区间上的常数12R^2随区域变大，光滑必须交代常数与区域。

###### paragraph：下降引理

1. 说明思路：把有限位移分成小段累加，坡度差不超过限速乘已走距离。
2. 陈述下降引理：线段在区域内时余项不超过L/2乘位移平方，并写出上界形式。
3. 证明：对一元限制函数用微积分基本定理，减去线性项，用Cauchy--Schwarz与Lipschitz条件积分。
4. 定义上界函数m_L，解释它是与目标相切、从上方盖住目标的碗，下半部分从下方托住目标。
5. 以1-cos x、L=1、x0=2为例说明曲线夹在两条抛物线之间。
6. 配图：1-cos x的二次上界与下界，上界最低点及其下方的真实值。

###### paragraph：上界怎样限制一步更新

1. 求上界最低点p=-g/L。
2. 代回得到一步保证下降量为梯度范数平方除以2L。
3. 在1-cos x上算出当前值1.416、碗底值1.003、真实值0.538，比较保证下降与实际下降。
4. 在贯穿例中算出碗底36、真实值32，说明上界的圆等高线落在目标的椭圆等高线之内。
5. 配图：贯穿例的椭圆等高线、上界的圆、从(9,1)到(8,0)的步。
6. 指出上界只知道一个L，按最陡方向提防，碗的类比在谷的走向上失效。

###### paragraph：局部模型能信多远

1. 强调线段要落在L成立的区域内，以x^4、x0=1、L=12给出上界。
2. 因式分解上界与目标之差，得出上界在[-3,1]上成立，其外失效。

4. 配图：x^4的上界全局图与当前点附近放大图，标出盖得住与盖不住的范围。

###### paragraph：上界与凸性无关

1. 说明上界总是凸的但L光滑与凸性互不蕴含，L限制弯曲大小，凸性限制弯曲方向。
2. 表：四个一元函数列出全局光滑与凸性的四种组合。
3. 比较两者对局部模型的贡献：光滑性给上界，凸性把下界提到切平面，由此才能从局部推断全局。

###### paragraph：下水平集上的常数

1. 指出下降算法留在下水平集内，引出只需下水平集上常数的引理。

###### paragraph：用Hessian估计光滑常数

1. 指出直接检验定义不方便，二阶可微时常数可由Hessian读出。
