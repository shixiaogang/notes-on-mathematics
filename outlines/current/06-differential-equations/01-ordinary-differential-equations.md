# 卷6《微分方程》：常微分方程大纲

## 部分主线与导读

部分主线：本部分研究由导数与初值确定的曲线。第1章建立初值问题、状态表示、解的检验和积分形式；第2章用矩阵指数和状态转移矩阵处理线性方程；第3章研究解的存在、唯一和延拓；第4章估计有限时间解对初值、参数和输入的敏感性，并建立流映射和伴随表达；第5章建立代表性数值方法。

部分导读（`\BookPartGuide`）的自然段：

1. 从落体、细菌和电路说明变化规律比量本身更容易写出，把规律和起点合成初值问题，提出能否求解、是否有解、对数据多敏感、算不出公式时怎样计算这些问题。

2. 说明第1章建立基本语言并求解简单方程，第2章处理线性方程。

3. 说明后三章不依赖解的公式，分别研究存在性、敏感性和数值计算。

4. 界定本部分只讨论有限时间的解，长期行为归卷九。

## 第1章 初值问题

正文入口：[`01-initial-value-problems.tex`](../../../tex/06-differential-equations/01-ordinary-differential-equations/01-initial-value-problems.tex)，章内依次安排方程与初值、状态表示、解的检验、一阶方程的解析求解、积分形式、可测输入和本章小结。

章职责与主线：从增长、冷却与摆的运动建立初值问题，分清规律、起点、未知曲线和存在区间；规定状态应包含哪些量；给出经典解的核验标准；用分离变量和代换求解具体方程并核对定义区间与丢失的解；再把方程改写为积分形式，并以此把解的概念推广到时间方向可测的输入。

章首导言：

1. 以咖啡降温等例子说明变化规律比量本身更容易写下来。
2. 说明规律不足以确定曲线，规律加起点才构成初值问题。
3. 列出全章要回答的具体问题：状态记录什么、公式凭什么算解、哪些方程能求解、右端跳变时解如何理解。
4. 说明各节沿这些问题依次展开的路线。

### 1.1 方程与初值

## 第2章 线性微分方程

正文入口：[`02-linear-differential-equations.tex`](../../../tex/06-differential-equations/01-ordinary-differential-equations/02-linear-differential-equations.tex)，章标签`chap:linear-differential-systems`。

章职责与主线：研究线性方程怎样把初始状态和外部输入变成可计算的响应。先用积分因子解标量方程，再用矩阵指数解常系数系统和高阶方程，用状态转移矩阵处理时变系统，用常数变易公式和因果Green函数处理输入，最后用单边Laplace变换把常系数方程化成代数方程。矩阵的谱分解、Schur形和Jordan块回用卷二，长期稳定和频率响应不在本章范围。

章首导言：

1. 用带加热器的水温方程说明未知函数只以一次出现，由此得到初值和输入的叠加性质。
2. 把一般线性问题概括为从初始状态和输入到响应的线性对应，提出全章问题：怎样明确算出这个对应。
